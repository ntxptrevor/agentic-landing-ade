# NTXP CPM Gantt Schedules knowledge store

Git-versioned, open-source, cloud-hosted (GitHub), mirrored to NTXP Forge. See ../references/self-improvement.md.

- `sections/` — one versioned file per backbone phase, module and classification table (generated by `../scripts/export_sections.mjs`; each section's version bumps only when its own content changes).
- `lessons-learned.md` — dated, removable changes with council votes.
- `memory.md` — global user directives (canon).
- `council/` — prompts, seat outputs, merge reports, anchor overrides.
- `metrics/schedule-drift.jsonl` — per-project drift metrics from canonical changelogs.
- `research/` — research sweep reports.
